# Macchina Fantasma

Theatrical intermedia performance composed and performed for UNT's Electronics Ensemble during the Fall 2026 semester. 

## controller
Engineered by me based on my [wearable motion controller](https://github.com/b1tcr4sh/wearable-motion-controller) platform. It's built into the shell of a hanging work lamp from Home Depot :3
